Personal Trainer Template

.NET 9 Vue 3 MySQL
Visit site Request demo access Back to portfolio

Reusable site template for personal trainers — services, a training tips blog, staff profiles, service locations, and testimonials, all editable from a custom admin panel. Built with .NET 9, Vue 3, and MySQL.

Goal: Give any personal trainer a professional site — services, blog, and testimonials — ready to launch and manage without touching code.
